# 招聘问答评测问题集模块

`自建招聘问答评测问题集 220 条（4 类意图 / 含 20 条边界样本），含试标→修正→全量→复核质控流程与格式清洗演示`

## 背景

招聘问答评测需要「问题集 + 标注规范 + 质控流程」三位一体。本模块从零构建一个覆盖 4 类意图、220 条的问题集，完整记录从 20 条试标对齐标准、规则修订、220 条全量标注到 10% 抽检复核的质控过程，并演示原始脏数据的格式清洗与结构化整理。

## 数据集说明

- **规模**：220 条（满足「200+」承诺），4 类意图各 55 条，结构均衡。
- **意图体系**：岗位查询 / 薪资咨询 / 技能要求 / 岗位推荐，定义与判定边界见 [docs/标注规范.md](docs/标注规范.md)。
- **难度结构**：easy 60 / medium 80 / hard 80；边界样本 20 条（约 9.1%，每类 5 条）。
- **构建方式**：11 条手写种子问题 × 5 个确定性问法变体（工具 `data/build_recruitment_qa.py` 可一键复现），保证问法多样性且全程可复现。
- **边界样本设计**：覆盖一题多意图、指代不明、行业黑话、薪资区间模糊表述四类边界，在种子层独立维护可追溯。

## 质控流程（试标 → 修正 → 全量 → 复核）

完整记录于 [docs/标注质控流程.md](docs/标注质控流程.md)，核心环节：

1. **试标**：20 条小样对齐口径，3 条边界样本暴露规则缺口；
2. **修正**：标注规范 v1→v2，2 处真实修订点（复合问题归类规则、推荐诉求优先级）；
3. **全量**：220 条按 v2 标注 intent / difficulty / boundary_case / notes；
4. **复核**：分层抽检 22 条 + 边界样本全量 20 条，一致率 97.6%（达预设 ≥95% 验收线）。

## 复现步骤

```bash

python dataset/data/build_recruitment_qa.py
# 2. 演示脏数据格式清洗（20 条 → clean_samples.csv，含清洗动作审计列）
python dataset/clean.py
# 3. 数据集构成分析 + 图表 + 报告
python dataset/analyze_dataset.py
```

## 局限性

- **单人标注**：未做双人独立标注计算 Kappa，复核为同人间隔 blind 重标；
- **场景聚焦**：围绕网络/运维/测试岗位，对其他岗位类型的覆盖需扩充种子；
- **清洗规则有限**：`clean.py` 的错别字修正依赖人工确认的替换表（5 处），不自动猜测；
- **意图体系简化**：4 类意图覆盖招聘主场景，未含「职业发展」「工作氛围」等长尾意图。
